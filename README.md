# 🖼️ Project Overview

An AI-powered customer intelligence platform designed to predict customer lifetime value (CLV), segment customers using RFM analytics, identify high-value customer groups, and support retention-focused business decision-making through interactive analytics dashboards, monitoring workflows, and automated reporting systems.

This platform focuses on:
- Customer lifetime value analytics
- RFM-based customer segmentation
- Customer retention intelligence
- Cohort & behavioral analytics
- Customer profitability analysis
- Customer 360 insights
- Drift monitoring workflows
- Executive-ready analytics dashboards

Built using:
- Streamlit
- XGBoost
- Scikit-learn
- SHAP
- Plotly
- Pandas & NumPy

# 📊 Key Customer Intelligence Insights

The analysis revealed several important customer value patterns:

### 🔹 High-frequency customers generated stronger lifetime value

Customers with higher purchase frequency consistently contributed higher long-term revenue.

### 🔹 RFM segmentation improved customer prioritization

RFM analytics helped identify:
- loyal customers
- high-value customers
- at-risk customers
- inactive customer groups

### 🔹 Customer behavior patterns shifted over time

Cohort analysis revealed changing customer engagement and purchasing behavior trends.

### 🔹 SHAP explainability improved interpretability

SHAP analysis highlighted the strongest factors driving customer lifetime value.

### 🔹 Drift monitoring improved model reliability

Behavioral drift detection helped identify evolving customer patterns.

These insights supported:
- retention strategy optimization
- customer targeting workflows
- customer profitability analysis
- long-term customer intelligence systems

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/girishshenoy16/Customer-Lifetime-Value-Analytics-System.git
cd Customer-Lifetime-Value-Analytics-System
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
```

---

## 3️⃣ Install Dependencies

```bash
python.exe -m pip install --upgrade pip
pip install -r requirements.txt
```

---

## 4️⃣ Install wkhtmltopdf (Required for PDF Reports)

Download and install wkhtmltopdf:

[wkhtmltopdf Official Download Page](https://wkhtmltopdf.org/downloads.html)

After installation, ensure wkhtmltopdf is added to your system PATH.

This is required for:
- PDF report generation
- executive summary exports
- downloadable analytics reports

---

# ▶️ Running the Project

## 1️⃣ Generate Synthetic Customer Dataset

Before launching the dashboard, generate the synthetic customer transaction dataset:

```bash
python data/synthetic_generator.py
```

This automatically:
- creates synthetic customer transaction data
- prepares raw datasets
- initializes analytics workflows
- prepares dashboard-ready pipelines

This produces:

* `data/raw/customers_transactions.csv`
* `data/processed/customer_status.csv`
* `data/processed/cart_events.csv`

---

## 2️⃣ Launch Streamlit Dashboard

```bash
streamlit run app/streamlit_app.py
```

---

# 🧰 Important Dashboard Workflows

After launching the dashboard, complete these workflows from the Streamlit sidebar:

---

## ✔ Run Data Cleaning Pipeline

Use the sidebar option:

➡️ Run Data Cleaning Pipeline

This:
- preprocesses customer records
- handles missing values
- prepares modeling datasets
- refreshes feature engineering workflows

---

## ✔ Train CLV Prediction Models

Use the sidebar option:

➡️ Train / Refresh CLV Models

This:
- trains XGBoost CLV models
- refreshes prediction pipelines
- updates model registry artifacts
- prepares customer intelligence workflows

---

## ✔ Generate Executive Reports

Use the Reports section to:

➡️ Generate Business Intelligence Reports

This automatically creates:
- executive summaries
- customer segmentation reports
- cohort analytics exports
- downloadable reporting assets

---

After completing these workflows, all dashboard modules become fully functional.
